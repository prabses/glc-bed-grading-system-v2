1. System Overview

The GLC Reports module is an automated, web-based interface integrated within Google Sheets, engineered to manage, generate, and distribute official academic records, report cards, and clearance forms directly from live grading databases.

1.1 Target Users & Core Functions

  • Target Users: Principal, Registrar, and Coordinator.
  • Core Function: Consolidates recorded student grades, attendance figures, and character evaluations across trimesters into standardized PDF documents and direct Google Drive exports.

Note: All operations performed within the GLC Reports system strictly adhere to role-based access control configured in the administrative sheets.

2. Key Sheets & Controls

The report generation environment relies on specific spreadsheet controls and dedicated administrative sheets to maintain security, dynamic signatory data, and audit logging.

2.1 GLC Reports Button

Located directly in the top spreadsheet menu bar. Clicking the GLC Reports button initiates and launches the Report Generator web application in a dedicated dialog/modal window.

2.2 Authorized Users Sheet

Defines system access permissions and privileges based on authenticated user email addresses. Access rights are structured as follows:

Assigned Role Allowed Report Types & Document Generation Distribution & Email Permissions
Principal & Coordinator Generate and save Periodical Letter Grade reports. Save to Google Drive folder destination.
Principal Only Generate and save Periodical Letter Grade reports. Send Periodical Letter Grade directly to the parent or guardian's registered email address.
Registrar Only Generate, compile, and print official school forms across Elementary, JHS, and SHS:
  • School Clearance (SC)
  • School Form 9 (SF9 / Report Card)
  • School Form 10 (SF10 / Permanent Record)
  • Numerical Grade Reports
 Export and compile official PDF records to designated Google Drive repositories.

2.3 Signatories Sheet

Stores, manages, and updates the official names, titles, and designations of authorized institutional signatories (e.g., Certified Correct, Principal, Registrar).

Automatic Sync: Updates made in the Signatories Sheet are automatically reflected in all newly generated Numerical Grade Reports, SF9 (Report Cards), and School Clearance (SC) documents without requiring script redeployment.

2.4 Generation Log Sheet

Maintains an immutable audit trail of document creation. Automatically records every generated report with key operational metadata:

  • Timestamp / Date: Exact date and time of file compilation.
  • Student Name: Complete name of the student for whom the report was generated.
  • User Email: Authenticated email of the user executing the generation.
  • Google Drive File Link: Direct hyperlink to the created PDF document in Google Drive.

2.5 Mail Log Sheet

Tracks and audits all electronic dispatches of Periodical Letter Grades sent to parents and guardians:

  • Timestamp: Date and time when the email was transmitted.
  • Student Name: Target student associated with the report card.
  • Parent Email: Recipient email address to which the record was delivered.
  • Delivery Status: Status flag (e.g., Sent, delivery confirmation).

3. How to Generate a Report

To start the generation workflow, click the GLC Reports button in the spreadsheet top menu bar to open the Report Generator web application. Follow the step-by-step procedure below:

3.1 Step 1: Choose the Report Type

Under the Select Report Type dropdown, pick the required document based on your assigned institutional role:

  • Principal / Coordinator: Select Periodical Letter Grade.
  • Registrar: Select Numerical Grade, School Clearance (SC), SF9 (Report Card), or SF10 (Permanent Record).

3.2 Step 2: Choose the Period

  1. Select the target School Year (e.g., 2026-2027).
  2. Select the specific Term:
    • 1st Trimester
    • 2nd Trimester
    • 3rd Trimester

3.3 Step 3: Choose the Class

  1. Select the Grade Level and corresponding Section.
  2. Senior High School (SHS) Classes: Select the applicable Strand (e.g., ABM, STEM, HUMSS, GAS).
  3. Basic Education (BED) Elementary & JHS Classes: Choose N/A for the strand selection.

3.4 Step 4: Choose Students & Action

Once the class roster is loaded into the interface, choose between the two execution options depending on your operational goal:

Option A: Generate Reports (Drive Export)
  1. Click the Generate Reports tab in the web application.
  2. Use the search bar to filter students, or use the checkboxes to select specific individuals (or leave all students selected for batch generation).
  3. Click the Generate Reports button.
  4. The system will generate standardized PDF documents, store them in the designated Google Drive folder, and automatically log the creation details in the Generation Log sheet.
Option B: Send via Email (Principal Only)

Access Restriction: This action is strictly restricted to the Principal role.

  1. Click the Send via Email tab in the web application.
  2. Inspect the student recipient list and verify email validity indicators:
    • Valid Email Address: Displayed in green with a checkmark (e.g., ✓ system.center@goldenlink.ph).
    • Missing / Unregistered Email: Displayed with a warning indicator (⚠ No email on file) and is automatically unchecked by default to prevent failed dispatches.
  3. Handling Missing Email Addresses:
    • Navigate to the Other Information sheet in the spreadsheet.
    • Input the missing parent or guardian email address for the student.
    • Return to the GLC Reports web application and click the Refresh Contacts button.
  4. Select the verified student recipients and click Send Reports via Email.
  5. The system dispatches the Periodical Letter Grade reports directly to the parent/guardian emails and automatically logs the transaction in the Mail Log sheet.

This working instruction document covers the complete functionality and operational workflow for the GLC Reports and Report Generation module. For additional support, system modifications, or role configuration, contact your systems developer.
