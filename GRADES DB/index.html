System Overview

The Grades Database is a Google Apps Script application that manages student grades for multiple academic years. The system provides two main interfaces:

  • Import Student Grades Form: For importing grades from OGS (Official Grade Sheet) template Google Sheets into academic year sheets
  • Update Student Grades Form: For searching and modifying individual grade periods for specific students and subjects

Both forms are accessible through the "Upload" menu in the Google Sheets interface and feature secure API architecture for data operations.

Academic Year Sheets

Before importing or updating student grades, ensure that your spreadsheet contains sheets named with the school year format (e.g., "2024-2025", "2023-2024"). These sheet names serve as the basis for the Academic Year dropdown selection in both the import and update forms. The dropdown only displays sheets that already exist and match the "YYYY-YYYY" format, so you must create the academic year sheet manually before importing data.

Import Student Grades Instructions

Accessing the Import Student Grades Form

  1. Open the main Google Sheets document containing the Grades Database
  2. Click on the "Upload" menu in the top menu bar
  3. Select "Import Student Grades" from the dropdown menu
  4. The Import Student Grades Form will open in a modal dialog window

Understanding the Import Student Grades Form Interface

The form contains the following fields:

  • Academic Year Dropdown: Select the target academic year sheet (e.g., "2024-2025")
  • Google Sheet Link Textarea: Paste the URL of the OGS template Google Sheet
  • Action Buttons: Cancel and Import Student Grades buttons

Importing Grades from OGS Template

  1. Select Academic Year

    • Click on the Academic Year dropdown
    • Select the academic year sheet where you want to import grades
    • The academic year sheet must already exist in your spreadsheet

  2. Get OGS Template Link

    • Open the OGS template Google Sheet that contains the grades you want to import
    • Copy the URL from the browser address bar
    • The URL should look like: https://docs.google.com/spreadsheets/d/SPREADSHEET_ID/edit

  3. Paste the Google Sheet Link

    • Click in the Google Sheet Link textarea
    • Paste the copied URL
    • Ensure the URL is complete and includes docs.google.com/spreadsheets

  4. Import the Grades

    • Click the "Import Student Grades" button
    • The button will show "Importing..." during the process
    • Wait for the success confirmation message
    • The form will automatically close upon successful import

  5. Verify the Import

    • Navigate to the selected academic year sheet in your spreadsheet
    • Verify that grade data appears starting from row 2 (row 1 contains headers)
    • Check that all subjects from the OGS template have been imported
    • Verify that student grades are correctly populated

Import Process Details

The import process:

  • Extracts Information: Automatically extracts advisor name, school year, level, and section from the OGS template
  • Processes All Subjects: Imports grades from all subject sheets in the OGS template (excluding Attendance, Character, Characters, and MAPEH sheets)
  • Handles MAPEH: For MAPEH subjects, only Final Grading and Final EQ are imported (grading periods are left empty)
  • Updates Existing Records: If a student-subject combination already exists, it updates the existing row
  • Inserts New Records: If a student-subject combination doesn't exist, it creates a new row
  • Preserves Order: Maintains the subject order from the OGS template

Import Student Grades Form Error Handling

  1. Missing Academic Year

    • If you don't select an academic year, an alert will prompt you to select one
    • Select an academic year from the dropdown before importing

  2. Invalid Google Sheet URL

    • If the URL doesn't contain docs.google.com/spreadsheets, an error will appear
    • Ensure you're using a valid Google Sheets URL
    • Copy the URL directly from the browser address bar

  3. Cannot Access OGS Template

    • If the system cannot access the OGS template, an error will show
    • Ensure you have access permissions to the OGS template spreadsheet
    • Verify the URL is correct and the spreadsheet exists

  4. No Subject Sheets Found

    • If no subject sheets are found in the OGS template, an error will appear
    • Ensure the OGS template contains at least one subject sheet with grades
    • Check that subject sheets are not named "Attendance", "Character", "Characters", or "MAPEH" (these are excluded)

  5. No Student Grades Found

    • If no student data is found in the OGS template, an error will show
    • Ensure the OGS template contains student grade data
    • Check that data rows start from row 10 in subject sheets

  6. Academic Year Sheet Not Found

    • If the selected academic year sheet doesn't exist, an error will appear
    • Create the academic year sheet manually before importing
    • Ensure the sheet name follows the "YYYY-YYYY" format

Update Student Grades Instructions

Accessing the Update Student Grades Form

  1. Open the main Google Sheets document containing the Grades Database
  2. Click on the "Upload" menu in the top menu bar
  3. Select "Update Student Grades" from the dropdown menu
  4. The Update Student Grades Form will open in a modal dialog window

Understanding the Update Student Grades Form Interface

The form contains the following fields:

  • Academic Year Dropdown: Select the academic year sheet to search
  • Student Number Input: Text field with autocomplete for searching student numbers
  • Subject Dropdown: Select the subject (populated after entering student number)
  • Load Grades Button: Button to load grade information
  • Current Grade Information Panel: Shows all current grade data in a grid layout (appears after loading)
    • Displays: Student Number, Full Name, Grade Level, Section, Subject, Teacher, 1st Initial, 2nd Initial, 3rd Initial, 4th Initial
  • Update Initial Grades Section: Shows current grades and input fields for updating
    • Current Grades Display: Shows all four initial grades
    • 1st Initial Input: Enter new grade for 1st grading period
    • 2nd Initial Input: Enter new grade for 2nd grading period
    • 3rd Initial Input: Enter new grade for 3rd grading period
    • 4th Initial Input: Enter new grade for 4th grading period
  • Remarks Input: Optional field for notes about the update
  • Action Buttons: Cancel and Update Grades buttons

Searching for Grade Information

  1. Select Academic Year

    • Click on the Academic Year dropdown
    • Select the academic year sheet where the student is enrolled
    • The student number autocomplete will populate based on the selected academic year

  2. Enter Student Number

    • Type the student number in the Student Number field
    • As you type, matching student numbers will appear in a dropdown
    • You can click on a suggestion or continue typing
    • Use arrow keys to navigate suggestions and Enter to select
    • After selecting a student number, the Subject dropdown will automatically populate

  3. Select Subject

    • After entering a student number, the Subject dropdown will become enabled
    • Select the subject for which you want to update grades
    • Only subjects that have grade records for the selected student will appear

  4. Load Grade Information

    • Click the "Load Grades" button
    • The button will show "Loading..." during the process
    • If found, grade information will appear in the Current Grade Information panel
    • The Update Section will become visible

  5. Search Results - Grades Found

    • All grade information will be displayed in the information panel
    • Current grades for all four periods will be shown
    • The Update Section will appear with pre-filled input fields
    • You can now modify the grades

  6. Search Results - Grades Not Found

    • An alert message will inform you that the grade record was not found
    • Verify the student number, academic year, and subject selection
    • Ensure the student has grade records for the selected subject

Updating Student Grades

  1. Prerequisites for Update

    • A student and subject must first be found using the search function (see previous section)
    • The form must be in "Update" mode with grade information displayed
    • The Update Section must be visible

  2. Review Current Grades

    • The current grades for all four periods are displayed at the top of the Update Section
    • Review the current values before making changes
    • Input fields are pre-filled with current values

  3. Enter New Grades

    • Modify the grades in the input fields for the periods you want to update
    • You can update one or more periods at once
    • Leave fields empty if you don't want to change that period's grade
    • Only fields with values will be updated

  4. Add Remarks (Optional)

    • Enter any notes or reasons for the update in the Remarks field
    • This information will be logged in the UPDATE LOG sheet
    • Remarks are optional but recommended for audit purposes

  5. Save Changes

    • Click "Update Grades" to save your changes
    • The button will show "Updating..." during the process
    • Only the periods with new values will be updated in the database
    • Wait for the success confirmation message

  6. After Successful Update

    • A success message will show which periods were updated
    • Each updated period will be logged separately in the UPDATE LOG sheet
    • The form will automatically close
    • You can verify the changes in the academic year sheet

Update Student Grades Form Error Handling

  1. Required Field Validation

    • If you try to update without selecting academic year, student number, or subject, an alert will prompt you
    • Ensure all required fields are filled before loading grades
    • Ensure at least one grade field has a value before updating

  2. No Grades to Update

    • If all entered grades are the same as current values, an error will be shown
    • Enter different values to proceed with the update

  3. Grades Not Loaded

    • If you try to update without loading grade information first, an alert will appear
    • Load grade information using the search function before updating

  4. Search Errors

    • If search fails, verify the student number format
    • Check that the correct academic year is selected
    • Ensure the student has grade records for the selected subject
    • Verify the subject exists in the dropdown

Data Management Instructions

Academic Year Sheets

  1. Sheet Naming Convention

    • Academic year sheets must follow the format "YYYY-YYYY" (e.g., "2024-2025")
    • Sheets are not automatically created - you must create them manually
    • Only sheets matching this format will appear in the Academic Year dropdown

  2. Sheet Structure

    • Row 1: Header row with column names
    • Row 2 onwards: Grade data rows
    • Expected columns (minimum 20):
      • Student Number (Column A)
      • Full Name (Column B)
      • Grade Level (Column C)
      • Section (Column D)
      • Subject (Column E)
      • Teacher (Column F)
      • 1st Initial (Column G)
      • 1st Transmuted (Column H)
      • 1st EQ (Column I)
      • 2nd Initial (Column J)
      • 2nd Transmuted (Column K)
      • 2nd EQ (Column L)
      • 3rd Initial (Column M)
      • 3rd Transmuted (Column N)
      • 3rd EQ (Column O)
      • 4th Initial (Column P)
      • 4th Transmuted (Column Q)
      • 4th EQ (Column R)
      • Final Grading (Column S)
      • Final EQ (Column T)

  3. Data Organization

    • Each academic year has its own sheet
    • Grade data is organized by academic year
    • Each row represents one student-subject combination
    • Student Number + Subject combination must be unique within each academic year

UPDATE LOG Sheet

  1. Automatic Logging

    • All grade updates are automatically logged
    • The UPDATE LOG sheet is created automatically if it doesn't exist
    • Each updated period creates a separate log entry

  2. Log Entry Information

    • Timestamp: When the update was made
    • Updated By: Email of the user who made the update
    • Student Number: The student's identification number
    • Full Name: The student's full name
    • School Year: The academic year sheet where the update was made
    • Subject: Which subject was updated
    • Period: Which grading period was updated (1st Initial, 2nd Initial, etc.)
    • Original Grade: The previous grade value
    • Updated Grade: The new grade value
    • Remarks: Any notes provided during the update

  3. Viewing Update Log

    • Navigate to the "UPDATE LOG" sheet in your spreadsheet
    • All updates are listed chronologically
    • Each period update is logged separately
    • Use filters to search for specific students, subjects, or time periods

Data Validation

  1. Student-Subject Uniqueness

    • Each Student Number + Subject combination must be unique within each academic year
    • The system updates existing records if the combination already exists during import
    • Updates only modify the Initial grades (1st, 2nd, 3rd, 4th Initial)

  2. Grade Updates

    • Only Initial grades can be updated through the Update form
    • Transmuted grades, EQ grades, and Final grades are not updated through this interface
    • Updates are logged chronologically by period

  3. Data Format

    • Grades are stored as text/numbers
    • Empty values are allowed for grades
    • The system preserves the exact format from the OGS template during import

OGS Template Requirements

  1. Template Structure

    • OGS templates should contain multiple subject sheets
    • Each subject sheet should have student grade data starting from row 10
    • Header information (Teacher, School Year, Level, Section) should be in rows 2-5 for subject sheets
    • For Attendance sheet, header information is in rows 1-4

  2. Subject Sheet Format

    • Row 9: Column headers (Student No, Student Name, etc.)
    • Row 10 onwards: Student data
    • Columns for regular subjects:
      • Column F (index 5): 1st Initial
      • Column G (index 6): 1st Transmuted
      • Column H (index 7): 1st EQ
      • Column L (index 11): 2nd Initial
      • Column M (index 12): 2nd Transmuted
      • Column N (index 13): 2nd EQ
      • Column R (index 17): 3rd Initial
      • Column S (index 18): 3rd Transmuted
      • Column T (index 19): 3rd EQ
      • Column X (index 23): 4th Initial
      • Column Y (index 24): 4th Transmuted
      • Column Z (index 25): 4th EQ
      • Column AA (index 26): Final Grading
      • Column AB (index 27): Final EQ

  3. MAPEH Subject Handling

    • MAPEH subjects are handled specially
    • Only Final Grading (column AF, index 30) and Final EQ (column AG, index 31) are imported
    • Grading periods (1st-4th Initial) are left empty for MAPEH

Troubleshooting Guide

Import Form Loading Problems

Issue: Import form doesn't open or shows errors
Solutions:

  1. Check your internet connection
  2. Refresh the browser page
  3. Close and reopen the form from the Google Sheets menu
  4. Ensure you have proper permissions to access the spreadsheet
  5. Check that the script is properly deployed

OGS Template Import Failures

Issue: OGS template doesn't import or shows errors
Solutions:

  1. Verify the Google Sheet URL is correct and complete
  2. Ensure you have access permissions to the OGS template spreadsheet
  3. Check that the OGS template contains at least one subject sheet
  4. Verify subject sheets have data starting from row 10
  5. Ensure header information (Teacher, Level, Section) is present in rows 2-5
  6. Check that the template is not corrupted or protected

Update Form Not Finding Grades

Issue: Grade search doesn't return results
Solutions:

  1. Verify the student number is correct
  2. Check that the correct academic year is selected
  3. Ensure the student has grade records for the selected subject
  4. Try typing the full student number without spaces
  5. Check the academic year sheet directly to confirm the grade record exists

Update Failures

Issue: Student grades don't update or shows errors
Solutions:

  1. Ensure all required fields are filled (academic year, student number, subject)
  2. Check that at least one grade field has a new value
  3. Verify you have write permissions to the spreadsheet
  4. Ensure your internet connection is stable
  5. Try refreshing the form and updating again
  6. Check the UPDATE LOG to see if the update was recorded

Academic Year Sheet Not Appearing

Issue: Academic year doesn't appear in the dropdown
Solutions:

  1. Verify the sheet name follows the format "YYYY-YYYY" (e.g., "2024-2025")
  2. Check that the sheet exists in the spreadsheet
  3. Ensure there are no extra spaces in the sheet name
  4. Create the sheet manually if needed (following the naming convention)
  5. Refresh the form to reload available sheets

Permission Errors

Issue: "Access denied" or permission-related error messages
Solutions:

  1. Verify you're logged into the correct Google account
  2. Check with your administrator about access permissions
  3. Ensure you have edit access to the spreadsheet
  4. Verify you have access to the OGS template spreadsheet (for imports)
  5. Try logging out and back into Google
  6. Contact your systems administrator for permission updates

UPDATE LOG Not Appearing

Issue: UPDATE LOG sheet doesn't exist or updates aren't logged
Solutions:

  1. The UPDATE LOG sheet is created automatically on first update
  2. Check if the sheet exists in your spreadsheet
  3. Verify updates are being saved (check the academic year sheet)
  4. Check script execution logs for errors
  5. The log may be in a different location if the sheet was renamed

Data Formatting Issues

Issue: Imported grades appear incorrectly formatted
Solutions:

  1. Check the OGS template structure matches expected format
  2. Verify column positions in the OGS template
  3. Review the source OGS template for formatting issues
  4. Re-import if necessary after fixing the OGS template

Script Execution Errors

Issue: Scripts fail to execute or timeout
Solutions:

  1. Check Tools → Script editor → Executions for error details
  2. Ensure the Web App URL is properly configured in Config.js
  3. Verify the API key is correct
  4. Check that the script is deployed as a web app
  5. Try running the script again after a few minutes
  6. Contact your systems developer if problems persist

MAPEH Grades Not Importing

Issue: MAPEH grades don't appear after import
Solutions:

  1. Verify the MAPEH sheet exists in the OGS template
  2. Check that Final Grading and Final EQ columns are populated
  3. Ensure the MAPEH sheet is not excluded (it should be included)
  4. Verify column positions (AF for Final Grading, AG for Final EQ)
  5. Check that student data exists in the MAPEH sheet

Duplicate Records

Issue: Duplicate student-subject combinations appear
Solutions:

  1. The system should automatically update existing records during import
  2. Check for duplicate rows manually in the academic year sheet
  3. Remove duplicates manually if they exist
  4. Re-import the OGS template to update existing records
  5. Verify the Student Number + Subject combination is unique
