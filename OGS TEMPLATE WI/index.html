1. System Overview

The Official Grade Sheet (OGS) is a Google Sheets file generated from the Template Masterfile system. It serves as the official record for student grades, attendance, and character development assessments.

The OGS file contains multiple sheets:

  • Subject Sheets: One sheet per subject assigned to the teacher (e.g., English, Math, Science, Filipino, etc.)
  • Attendance Sheet: For tracking monthly student attendance
  • Character Sheet: For assessing student behavioral traits

Key features:

  • Student information is automatically populated from the Students Database
  • Grade calculations (Transmuted, EQ, Final Grading) are automatic
  • Attendance calculations (Days Absent) are automatic
  • Character EQ calculations are automatic

File naming format: OGS-GRADE-[Level][Section]-[School Year] - [Teacher Name]

Example: OGS-GRADE-2A-2026-2027 - Cerado, Marites

1.1 Quick Start Guide & Prerequisites

Prerequisites:

  • A Google account with edit permissions for the OGS file
  • The OGS file has been generated from the Template Masterfile
  • Access to the Template Masterfile to locate the OGS link

To input subject grades:

  1. Open the OGS file from the Template Masterfile
  2. Click on a subject sheet tab (e.g., English, Math, Science)
  3. Enter scores in the Written, Performance, and Assessment columns for each grading period
  4. Transmuted grades and EQ values will be calculated automatically

To input attendance:

  1. Click on the Attendance sheet tab
  2. Enter the School Days for each month
  3. Enter Days Present for each student
  4. Days Absent will be calculated automatically

To input character grades:

  1. Click on the Character sheet tab
  2. Enter the Grade for each behavioral trait per student
  3. EQ values will be calculated automatically

2. Accessing the Official Grade Sheet

  1. Open the Template Masterfile Google Sheets document
  2. Navigate to the MASTER_DATA sheet
  3. Find the row containing your class information (School Year, Grade Level, Section, Teacher)
  4. Click on the Template Link hyperlink in that row
  5. The Official Grade Sheet will open in a new browser tab

Note: The OGS link is automatically created when the template is exported from the Template Masterfile. If you cannot find the link, contact your administrator or generate a new template.

3. Understanding the OGS File Structure

Sheet Tabs

At the bottom of the OGS file, you will see multiple sheet tabs:

Tab Type Examples Purpose
Subject Sheets English, Math, Science, Filipino, Sibika at Kultura, Music, Art, PE, Health, Computer, HELE, TLE, Values Record academic grades
Attendance Attendance Track monthly attendance
Character Character Assess behavioral traits

Tip: Click on any tab to switch between sheets. Use the arrow buttons at the bottom-left if there are many tabs.

Header Information

Each sheet contains header information in the top rows that is automatically populated:

Subject Sheets (Rows 2-7):

  • Teacher Name, School Year, Level, Section, Total Student, Subject

Attendance & Character Sheets (Rows 1-6):

  • Advisor Name, School Year, Level, Section, Total Student, EQ Legend (Character only)

Important: Do not modify header information as it is pre-filled from the system.

Protected Cells (Gray Colored)

Cells with a gray background contain formulas and should not be edited. These include:

  • Transmuted grade columns
  • EQ columns
  • Days Absent columns
  • Final Grading columns
  • Header information cells

Warning: Do not type in gray-colored cells. Doing so will overwrite the formulas and break the automatic calculations.

4.2 Step-by-Step: Entering Subject Grades

Step 1: Select the Subject Sheet

  1. Click on the subject tab at the bottom of the screen (e.g., English, Math)
  2. The sheet will display the student list and grading columns

Step 2: Locate the Grading Period

  1. Find the grading period you want to input (1ST GRADING, 2ND GRADING, etc.)
  2. The grading period header spans across the Written, Performance, and Assessment columns

Step 3: Enter Written Scores

  1. Click on the TS1-Written cell (or TS2, TS3, TS4 for other periods) for the first student
  2. Type the student's written work score
  3. Press Enter or Tab to move to the next cell
  4. Continue entering scores for all students

Step 4: Enter Performance Scores

  1. Move to the TS1-Performance column
  2. Enter the performance task score for each student
  3. Continue until all students have scores

Step 5: Enter Assessment Scores

  1. Move to the TS1-Assessment column
  2. Enter the assessment score for each student
  3. Continue until all students have scores

Step 6: Verify Auto-Calculated Values

  1. After entering all three components, check the Transmuted column
  2. The transmuted grade should appear automatically
  3. The EQ column will show the equivalent rating (A, P, AP, D, B)

Step 7: Repeat for Other Grading Periods

  1. Repeat Steps 3–6 for 2ND, 3RD, and 4TH GRADING periods
  2. After all four periods are complete, the Final Grading and Final EQ columns will calculate automatically

5.2 Step-by-Step: Entering Attendance

Step 1: Select the Attendance Sheet

  1. Click on the Attendance tab at the bottom of the screen
  2. The sheet will display the student list and monthly attendance columns

Step 2: Enter School Days

  1. For each month, enter the total number of school days in the School DAYS column
  2. This value is typically the same for all students in a given month

Tip: You can enter the School Days value once and copy it down for all students in that month.

Step 3: Enter Days Present

  1. For each student, enter the number of days they were present in the Days PRESENT column
  2. Move down the column to enter for all students

Step 4: Verify Days Absent

  1. The Days ABSENT column will automatically calculate (School Days - Days Present)
  2. Verify that the values are correct

Step 5: Repeat for Each Month

  1. Repeat Steps 2–4 for each month of the school year
  2. Move to the next month's columns and enter the data

Example Attendance Entry:

Student Name School DAYS (July) Days PRESENT (July) Days ABSENT (July)
Flores, Antonio 22 20 2 (auto)
Bautista, Catherine 22 22 0 (auto)
Torres, Daniel 22 18 4 (auto)

6.2 Step-by-Step: Entering Character Grades

Step 1: Select the Character Sheet

  1. Click on the Character tab at the bottom of the screen
  2. The sheet will display students with their behavioral traits

Step 2: Understand the Layout

  1. Each student has multiple rows — one for each behavioral trait
  2. The Student No and Student Name repeat for each trait row
  3. The TRAITS column shows which trait is being graded

Step 3: Enter Grades for Each Trait

  1. Locate the first student's first trait row
  2. Enter the grade in the 1st Grade column (use the grading scale above)
  3. Move down to enter grades for each trait
  4. Continue until all traits for all students are graded

Step 4: Verify Auto-Calculated EQ

  1. The 1st EQ column will automatically display the equivalent rating
  2. Check that the EQ matches the expected value based on the grade entered

Step 5: Repeat for Other Grading Periods

  1. Repeat the process for 2nd Grade, 3rd Grade, and 4th Grade columns
  2. Each period's EQ will calculate automatically

7. Important Reminders

Do's:

  • Save your work regularly (Google Sheets auto-saves, but verify the "All changes saved" indicator)
  • Double-check entries before moving to the next student or period
  • Use the correct grading period columns (1st, 2nd, 3rd, 4th)
  • Verify auto-calculated values appear correctly
  • Enter 0 if there is no score (do not leave input cells blank)

Don'ts:

  • Do not edit gray-colored cells (these contain formulas)
  • Do not modify header information (pre-filled from the system)
  • Do not delete rows or columns (this will break formulas)
  • Do not rename sheet tabs (the system relies on specific sheet names)
  • Do not manually add or modify student information in the OGS

Data Entry Tips:

  • Use Tab key to move to the next cell (right)
  • Use Enter key to move to the cell below
  • Use arrow keys for precise navigation
  • If an auto-calculated cell shows an error, you may have accidentally edited it

8. Troubleshooting Guide

8.1 Auto-Calculated Values Not Appearing

Problem: Transmuted, EQ, or Days Absent columns show blank or error

Solutions:

  1. Verify that you entered values in all required input columns
  2. Check if the formula was accidentally deleted (cell should have gray background)
  3. Do not leave input cells blank — enter 0 if there is no score
  4. Contact your administrator if formulas need to be restored

8.2 Error Messages in Cells

Problem: Cells show #REF!, #VALUE!, #DIV/0!, or other errors

Solutions:

  1. #REF! — A referenced cell was deleted; contact administrator
  2. #VALUE! — Invalid data type entered; ensure you're entering numbers only
  3. #DIV/0! — Division by zero; check if School Days is entered (for attendance)
  4. Do not attempt to fix formula errors yourself; contact your administrator

8.3 Cannot Edit Cells

Problem: Clicking on a cell does not allow typing

Solutions:

  1. The cell may be protected — check if it's a gray-colored (formula) cell
  2. You may not have edit permissions — contact your administrator
  3. Try refreshing the browser page
  4. Verify your access level with your administrator

8.4 Student List Issues

Problem: Missing students or wrong student information

Solutions:

  1. Student data is pulled from the Students Database at the time of template generation
  2. If students were added after template generation, contact your administrator to regenerate the template
  3. Do not manually add or modify student information in the OGS

8.5 File Access Issues

Problem: Cannot open the OGS file from the Template Masterfile link

Solutions:

  1. Verify you are logged into the correct Google account
  2. Check with your administrator about file access permissions
  3. The file may have been moved or deleted — contact your administrator
  4. Try accessing Google Drive directly and search for the file name

8.6 Changes Not Saving

Problem: Edits disappear or don't persist

Solutions:

  1. Check your internet connection
  2. Look for "Saving..." or "All changes saved" indicator in Google Sheets
  3. Refresh the page and verify if changes were saved
  4. Avoid closing the browser immediately after making changes
  5. Verify you have edit (not just view) permissions

8.7 Wrong Grading Period Data

Problem: Entered data in the wrong grading period column

Solutions:

  1. Clear the incorrectly entered data (select cells and press Delete)
  2. Re-enter the data in the correct grading period columns
  3. Double-check column headers before entering data
  4. Use the grading period header row as a guide (1ST GRADING, 2ND GRADING, etc.)
