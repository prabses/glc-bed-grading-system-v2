1. System Overview

The Students Database is a Google Apps Script application that manages student information across multiple academic years. The system provides two main interfaces:

  • Import Student Data Form: For importing student records from CSV files into academic year sheets
  • Update Student Information Form: For searching and modifying existing student records

Both forms are accessible through the Upload menu in the Google Sheets interface.

1.1 Quick Start Guide & Prerequisites

Before using the Students Database, ensure you have the following:

  • A Google account with access to the Students Database spreadsheet
  • Edit permissions for the spreadsheet (contact your administrator if needed)
  • For importing: A properly formatted CSV file containing student data
  • A stable internet connection

To import student data:

  1. Open the spreadsheet → Click Upload menu → Select Import Student Data
  2. Choose an academic year from the dropdown
  3. Click Choose File and select your CSV file
  4. Click Import Data and wait for confirmation

To update student information:

  1. Open the spreadsheet → Click Upload menu → Select Update Student Information
  2. Choose an academic year and enter the student number
  3. Click Load Student to retrieve the student's information
  4. Select the field to update, enter the new information, and click Update Information

2. Import Student Data Instructions

2.1 Accessing the Import Student Data Form

Important: You must create the academic year sheet manually before you can import data into it. If you need to create a new academic year sheet, see Section 4.2: Creating a New Academic Year Sheet for step-by-step instructions.

  1. Open the main Google Sheets document containing the Students Database
  2. Click the Upload menu in the top menu bar
  3. Select Import Student Data from the dropdown menu
  4. The Import Student Data Form will open in a modal dialog window

2.2 Step-by-Step Import Process

Step 1: Select Academic Year

  1. Click the Academic Year dropdown

  1. Select the academic year sheet where you want to import the data

Note: If the year you need doesn't appear, see Section 4.2 to create a new academic year sheet.

Step 2: Prepare Your Students Information CSV File

Your CSV file must have the following headers in this exact order:

Column 1 Column 2 Column 3 Column 4 Column 5 Column 6 Column 7 Column 8
Student Number Last Name First Name Middle Name Grade Level Section Strand Gender

Sample CSV File Format with Students Data:

Important Requirements:

  • The first row must contain these exact headers (spelling and capitalization matter)
  • Student data rows should start from the second row
  • Each student number must be unique within the file
  • Save your file in CSV (.csv) format

Tip: You can create a CSV file by exporting from Excel (File → Save As → CSV) or Google Sheets (File → Download → Comma-separated values).

Step 3: Upload the Students Information CSV File

  1. Click the Choose File button

  1. Navigate to your CSV file and select it

  1. The file name will appear in the input field once selected

Step 4: Import the Data

  1. Click the Import Data button

  1. The button will display Importing... while processing

  1. Wait for the success confirmation message

  1. The form will automatically close upon successful import

Step 5: Verify the Import

  1. Navigate to the selected academic year sheet in your spreadsheet
  2. Verify that the student data appears starting from row 3 (rows 1-2 contain headers)
  3. Confirm that all columns are properly populated

2.3 Import Error Messages and Solutions

Duplicate Student Numbers

What it means: The CSV file contains one or more students with the same student number.

How to fix it:

  1. Open your CSV file in Excel or Google Sheets
  2. Find and remove the duplicate student numbers listed in the error message
  3. Save the file and try importing again
CSV Format Errors

What it means: The headers in your CSV file don't match the required format.

How to fix it:

  1. Verify that your headers are exactly: Student Number, Last Name, First Name, Middle Name, Grade Level, Section, Strand, Gender
  2. Check for extra spaces before or after header names
  3. Ensure your file is saved as CSV format (not Excel or other formats)
Empty CSV File

What it means: The CSV file contains no student data or headers.

How to fix it:

  1. Open your CSV file and ensure it contains data rows below the header row
  2. Save the file and try importing again
Missing Academic Year

What it means: You clicked Import Data without selecting an academic year.

How to fix it:

  1. Select an academic year from the dropdown
  2. Click Import Data after selecting an academic year

3. Update Student Information Instructions

3.1 Accessing the Update Student Information Form

  1. Open the Google Sheets document containing the Students Database
  2. Click the Upload menu in the top menu bar
  3. Select Update Student Information from the dropdown menu
  4. The Update Student Information Form will open in a modal dialog window

3.2 Step-by-Step Update Process

Step 1: Select Academic Year

  1. Click the Academic Year dropdown
  2. Select the academic year sheet where the student is enrolled

Step 2: Enter Student Number

  1. Type the student number in the Student Number field
  2. As you type, matching student numbers will appear in a dropdown list
  3. Click on a suggestion to select it, or continue typing the full number

Tip: Use the arrow keys to navigate through suggestions and press Enter to select.

Step 3: Load Student Information

  1. Click the Load Student button

  1. The button will display Loading... while processing

  1. If found, the student information will appear in the Current Student Information panel

  1. The Update Section will become visible below

If the student is found:

All student fields will be displayed, and you can proceed to update.

If the student is not found:

An error message will appear. Verify that:

  • The student number is correct
  • You selected the correct academic year
  • The student exists in that academic year's sheet

Step 4: Select Field to Update

  1. Click the Field to Update dropdown

  1. Select the field you want to modify (e.g., Last Name, First Name, Grade Level, etc.)

  1. The current value will automatically appear in the Current Value display

Note: Student Number cannot be updated because it serves as the unique identifier for each student.

Step 5: Enter New Information

  1. Type the new information in the New Value field

  1. Double-check that the new information is correct before proceeding

Step 6: Add Remarks (Optional)

  1. Enter any notes explaining the reason for the update in the Remarks field

  1. This information will be recorded in the Update Log for audit purposes

Recommendation: Always add remarks to maintain a clear record of why changes were made.

Step 7: Save the Changes

  1. Click the Update Information button

  1. The button will display Updating... while processing

  1. A success message will confirm the update, showing both the old and new information

  1. The change is automatically recorded in the Update Log sheet

3.3 Update Error Messages and Solutions

No Field Selected

What it means: You clicked Update Information without selecting a field to update.

How to fix it: Select a field from the "Field to Update" dropdown before proceeding.

Same Value Error

What it means: The new information you entered is identical to the current value.

How to fix it: Enter information that is different from the current value.

Student Not Loaded

What it means: You attempted to update without first loading a student's information.

How to fix it: Enter a student number and click Load Student before attempting to update.

4. Data Management Instructions

4.1 Academic Year Sheet Structure

Each academic year sheet follows this structure:

  • Rows 1–2: Header rows (managed by the system)
  • Row 3 onwards: Student data rows
  • Columns: Student Number, Last Name, First Name, Middle Name, Grade Level, Section, Strand, Gender

4.2 Creating a New Academic Year Sheet

Follow these steps to create a new academic year sheet:

Step 1: Duplicate an Existing Sheet

  1. Right-click an existing academic year sheet
  2. Select Duplicate

A copy of the sheet will be created.

Step 2: Rename the Sheet

  1. Right-click the copied sheet
  2. Select Rename
  3. Enter the new academic year in "YYYY-YYYY" format (e.g., "2025-2026")

Step 3: Protect the Sheet

  1. Right-click the renamed sheet
  2. Select Protect sheet
  3. In the sidebar that appears, click Set permissions

  1. Select Restrict who can edit this range
  2. Choose Only you from the dropdown (or select Custom to add specific collaborators)
  3. Click Done

Step 4: Clear Existing Student Data

  1. Select all student data rows (row 3 onwards)

  1. Delete the content (do not delete the header rows 1–2)
  2. The new academic year sheet is now ready for student data import

4.3 Understanding the Update Log

The Update Log automatically records every change made to student information, providing a complete audit trail for all modifications. This sheet is created automatically when the first update is made.

Log Entry Fields:

Field Description
Timestamp Date and time when the update was made
Updated By Email address of the user who made the update
Student Number The student's identification number
Academic Year The academic year sheet where the update occurred
Field Updated Which field was changed
Old Value The previous value before the update
New Value The new value after the update
Remarks Notes provided during the update

Tip: You can use filters to search for specific students, date ranges, or types of changes in the Update Log.

5. Troubleshooting Guide

5.1 Import Form Loading Problems

Problem: Import form doesn't open or shows errors

Solutions:

  1. Check your internet connection
  2. Refresh the browser page
  3. Close and reopen the form from the Google Sheets menu
  4. Ensure you have proper permissions to access the spreadsheet
  5. Check that the script is properly deployed

5.2 CSV Import Failures

Problem: CSV file doesn't import or shows format errors

Solutions:

  1. Verify CSV headers match exactly: Student Number, Last Name, First Name, Middle Name, Grade Level, Section, Strand, Gender
  2. Check that the CSV file is saved in UTF-8 encoding
  3. Ensure there are no special characters causing parsing issues
  4. Check that student numbers are unique within the file
  5. Ensure data rows start from row 2 (row 1 is headers)

5.3 Duplicate Student Number Errors

Problem: Import fails due to duplicate student numbers

Solutions:

  1. Review the error message to identify duplicate student numbers
  2. Remove duplicate entries from your CSV file
  3. Check the academic year sheet for existing student numbers
  4. Re-import the corrected CSV file

5.4 Update Form Not Finding Students

Problem: Student search doesn't return results

Solutions:

  1. Verify the student number is correct
  2. Check that the correct academic year is selected
  3. Ensure the student exists in the selected academic year sheet
  4. Try typing the full student number without spaces

5.5 Update Failures

Problem: Student information doesn't update or shows errors

Solutions:

  1. Ensure all required fields are filled (field selection and new information)
  2. Check that the new information is different from the current value
  3. Verify you have write permissions to the spreadsheet
  4. Ensure your internet connection is stable
  5. Try refreshing the form and updating again

5.6 Academic Year Sheet Not Appearing

Problem: Academic year doesn't appear in the dropdown

Solutions:

  1. Verify the sheet name follows the format "YYYY-YYYY" (e.g., "2024-2025")
  2. Check that the sheet exists in the spreadsheet
  3. Ensure there are no extra spaces in the sheet name
  4. Create the sheet manually if needed (see Section 4.2)
  5. Refresh the form to reload available sheets

5.7 Permission Errors

Problem: "Access denied" or permission-related error messages

Solutions:

  1. Verify you're logged into the correct Google account
  2. Check with your administrator about access permissions
  3. Ensure you have edit access to the spreadsheet
  4. Contact your systems administrator for permission updates

5.8 Update Log Not Appearing

Problem: Update Log sheet doesn't exist or updates aren't logged

Solutions:

  1. The Update Log sheet is created automatically on the first update
  2. Check if the sheet exists in your spreadsheet
  3. Verify updates are being saved (check the academic year sheet)

5.9 Data Formatting Issues

Problem: Imported data appears incorrectly formatted

Solutions:

  1. Data is intentionally left-aligned to prevent auto-formatting
  2. Check the CSV file encoding (should be UTF-8)
  3. Verify special characters are properly handled
  4. Re-import if necessary after fixing the CSV file

5.10 Script Execution Errors

Problem: Scripts fail to execute or timeout

Solutions:

  1. Contact your systems developer

This working instruction document covers the complete functionality of the Students Database system. For additional support or system modifications, contact your systems developer.
